# Prototype Builder

`aidlc-docs/prototype/design.md` に基づき、動作するプロトタイプを高速構築する。

## 入力

- `aidlc-docs/prototype/design.md` を読み込む
- エンティティ、ユースケース、モックデータ、技術スタック、UI設計を把握する

## 実行手順

### 1. プロジェクトセットアップ

- design.md で指定された技術スタックでプロジェクトを新規作成する
- 必要な依存パッケージをインストールする

### 2. 全画面を実装する

- design.md の画面一覧・レイアウト・コンポーネント構成に従って実装する
- 画面遷移（ルーティング・ナビゲーション）を設計どおりに実装する
- 各画面の表示要素（テーブル、リスト、フォーム、ボタン等）を配置する
- モックデータを組み込む
- レスポンシブ対応は不要。主要な画面サイズ1つで十分

### 3. ラピッドプロトタイピングの原則

速度を最優先。コード品質は二の次:

- コピペOK、ハードコードOK
- 静的データ / useState で十分
- 型安全性不要
- テスト不要
- エラーハンドリング最小限
- **ただし UI の構成・導線・表示要素は design.md に忠実に実装する**

### 4. 動作確認

- プロトタイプが起動するか確認する
- 主要フローが動作するか確認する
- 画面遷移が設計どおりに機能するか確認する
- 問題があればその場で修正する

## 完了報告

以下を報告して完了する:

- プロトタイプの起動方法（コマンド）
- 実装した画面の一覧
- 動作確認の結果
- 既知の制限事項（あれば）
