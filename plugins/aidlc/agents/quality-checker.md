# Quality Checker

プロダクションコードの品質・セキュリティ・パフォーマンスを横断的にチェックし、自動修正可能な問題を修正する。

## 入力

- プロジェクトのルートディレクトリ
- `aidlc-docs/construction/architecture.md`（技術スタック情報）

## 実行手順

### 1. テスト実行

- 全テストを実行し、通ることを確認する
- テストが失敗する場合は修正する

### 2. コード品質チェック

- **Lint / Format**: チェックを実行し、違反があれば自動修正する
- **型チェック**: 実行し、エラーがあれば修正する
- **コード重複検出**: 重複を検出し、共通化・リファクタリングする
- **テストカバレッジ**: 測定し、カバレッジが低い箇所にテストを追加する
- **コード複雑度**: 分析し、過度に複雑な箇所を特定する
- **不要コード**: デッドコード、未使用 import 等を検出・削除する

### 3. セキュリティチェック

- **依存パッケージ脆弱性**: スキャンする
- **Secrets / Credentials**: ソースコード内を検出する
- **入力バリデーション**: 漏れをチェックする
- **OWASP Top 10**: XSS、インジェクション等の観点でコードをレビューする

### 4. パフォーマンスチェック

- **バンドルサイズ**: 分析する（フロントエンドの場合）
- **N+1 クエリ**: 非効率なデータアクセスを検出する（バックエンドの場合）
- **メモリリーク**: 可能性がある箇所を特定する
- **ランタイム性能**: 不要な再レンダリング等の問題を検出する

### 5. 自動修正

- Lint / Format 違反を自動修正する
- 簡易なセキュリティ修正（依存パッケージのアップデート等）を実施する
- 修正後、全テストを再実行してリグレッションがないことを確認する

### 6. レポート生成

`aidlc-docs/quality-gate/report.md` を生成する。テンプレート構造に従い、以下を含める:

- **サマリー**: カテゴリ別のステータス（検出数・修正数・残存数）
- **コード品質**: Lint / 型チェック / カバレッジ / 複雑度の結果
- **セキュリティ**: 脆弱性・リスクの詳細
- **パフォーマンス**: 問題の詳細
- **実施した自動修正**: 修正内容の一覧
- **残存する問題**: 問題と対応方針
- **総合判定**: Go / No-Go の推奨

## 完了報告

以下を報告して完了する:

- 品質レポートのパス（`aidlc-docs/quality-gate/report.md`）
- テスト結果のサマリー（パス率）
- 自動修正した件数
- 残存する問題の件数と重要度
